# 人狼ゲーム v0.6.2

ブラウザで遊べるオンライン人狼ゲームです。人間1人＋CPUから最大30人まで対応します。
外部AI API・外部画像・外部フォントは使いません。サーバーはNode.js標準機能だけで動きます。

## v0.6.2 で直したところ

- オンライン部屋のコードを自分で決められるようにしました。3〜16文字の文字・数字・`-`・`_`が使え、空欄なら従来どおり自動生成します。
- 管理画面にサーバー監視を追加しました。稼働時間、メモリ、Node/PID、SSE接続数、HTTP/API要求数、最近のエラーを確認できます。
- 管理画面から「CPU観戦部屋」を作れるようにしました。人間0人・CPU4〜30人で自動対戦し、役職を見ながら盤面を観戦できます。`CPU早送り ×8` と `1フェーズ進める` に対応します。
- 役職カードは、めくってから **約10.5秒** 表示。占い・霊媒の結果カードも **約7.2秒** 表示します。表のカードをもう一度タップするとすぐ閉じられます。
- スマホでは本文16pxを基準に、プレイヤー名、アイコン、吹き出し、矢印ラベル、下部ナビ、行動ボタンを拡大しました。
- CPU会話を再調整し、丁寧語だけに寄らないようにしました。直接質問、前日の投票理由、疑われた時の返答、占い・霊媒報告が会話としてつながるようにしています。
- 招待URLは現在の部屋コードから組み立て直して共有するため、別端末でも同じ部屋へ入りやすくしています。
- `START-ONLINE-WINDOWS.bat` はローカルサーバーの `/health` を確認してからngrokを起動します。


## v0.6.2 の中心変更

### 盤面型UI

従来の「チャット一覧だけ」ではなく、プレイヤーを村の周囲に配置する盤面を追加しました。

- 直近の発言: 発言者の近くに吹き出し表示
- 怪しい: 薄い疑い矢印
- 白寄り: 別色の薄い矢印
- 質問: 点線矢印
- 占い主張: 占い色の矢印＋白/黒
- 霊媒主張: 霊媒色の矢印＋白/黒
- 投票結果: 開票時に太く濃い矢印を一斉表示
- 夜の自分の選択: 本人にだけ矢印プレビュー

占い・霊媒の矢印は「システムが真実を保証する表示」ではありません。全員が使える公開主張なので、人狼・狂人などの騙りにも使えます。

投票中の他人の投票先は公開されません。後出し有利を作らないため、全票は開票後にだけ盤面へ表示します。

### スマホ画面

ゲーム中は下部の3画面を切り替えます。

- `盤面`: 人、吹き出し、矢印、ナレーション
- `会話`: 読み返し用のチャットログ
- `自分`: 役職カード、夜能力、自分だけの記録

昼は盤面、夜は自分、投票は盤面へ自動で切り替わります。PCでは盤面・会話・自分情報を同時表示します。

### ナレーション

フェーズ開始、朝、投票開始などは盤面中央のナレーションで通知します。
死亡・処刑は盤面を覆う短い演出を入れ、誰が死亡したか見落としにくくしています。

### 秘密カード

役職・占い結果・霊媒結果は常時表示せず、本人だけに一時カードとして表示します。

1. 裏向きカードを表示
2. タップでめくる
3. 放置しても一定時間で自動的にめくる
4. 表示時間が終わると裏へ戻り、フェードアウト

役職を見直したい場合は `自分` 画面の「役職カードを見る」から再表示できます。能力結果は「自分だけの記録」にも残ります。

### CPU会話 v0.6.2

CPUごとに次の性格値を固定生成します。

- 口調: くだけた / やわらかい / 丁寧 / 短く率直 / 理屈っぽい
- 発言量
- 自信の強さ
- 疑い深さ
- 反応速度
- 行動テンポ
- 文章量
- 軽い感情表現の出やすさ

CPUは「全員同じ敬語文章」にしないよう、発言内容自体も変わります。

- 疑う
- 白寄りに見る
- 理由を質問する
- 名指しされた時だけ遅れて返答する
- 占い・霊媒結果を優先報告する
- 騙り役は偽結果を出す
- 過去の投票・公開CO・公開判定を判断材料にする

CPU同士の無限返信は抑止しています。公開情報と本人が知ってよい秘密情報以外はCPUへ渡しません。

## Windowsで起動

Node.js 22以上が必要です。npmパッケージの追加インストールは不要です。

`START-WINDOWS.bat` をダブルクリックするか、PowerShellで:

```powershell
node server.js
```

起動例:

```text
Werewolf Game v0.6.2
Game:  http://localhost:3000
Admin: http://localhost:3000/admin
Admin password: xxxxxxxxxxxx
```

ゲーム:

```text
http://localhost:3000
```

管理画面:

```text
http://localhost:3000/admin
```

管理者パスワードを固定する場合:

```powershell
$env:ADMIN_PASSWORD="自分だけの長いパスワード"
node server.js
```

管理者パスワードは友達へ送らないでください。

## ngrokで外部テスト

サーバーを起動したまま別のPowerShellで:

```powershell
ngrok http 3000
```

表示されたHTTPS URLを共有します。ゲーム内の「招待リンクをコピー」を使えば部屋コード込みのURLを送れます。

今のngrok方式ではNode.jsとngrokの両方を起動しておく必要があります。詳しくは `ONLINE-WINDOWS.md` を参照してください。

## 部屋コード

部屋作成時にコードを自分で決められます。

- 3〜16文字
- 文字・数字・`-`・`_`
- 日本語の文字も使用可能
- 英字は大文字として扱います
- 同じコードの部屋が存在する場合は作成できません
- 空欄なら `0/O`、`1/I` など紛らわしい文字を避けた5文字コードを自動生成します

招待リンクを使えば、参加者側はコードを入力しなくても同じ部屋へ入れます。

## 管理画面

`/admin` は開発者専用です。通常プレイヤー向けの通信には他人の役職やCPU内部状態を含めません。

### サーバー監視

- サーバー稼働時間
- RSS / Heapメモリ
- Node.jsバージョン、PID、OS
- Tick間隔、最大部屋数
- HTTP / API要求数
- 現在のSSE接続数
- 管理者セッション / 一時接続チケット
- 最近のサーバー / APIエラー

### 部屋監視

- 人数、フェーズ、日数、接続状態
- 全員の役職・生死・恋人
- 夜行動・投票先
- 公開 / 人狼 / 幽霊チャット
- CPU人格、疑いスコアと理由
- CPUの騙り状態、返信待ちなど

### CPU観戦ラボ

管理画面から人間0人のCPU専用試合を作れます。CPU人数は4〜30人。円形盤面に全CPUの役職と直近会話を表示し、`CPU早送り ×8`、通常速度への復帰、`1フェーズ進める`、観戦部屋削除ができます。

## 役職

合計4〜30人。基本役職16種類＋追加状態「恋人」。

- 村人陣営: 村人、占い師、霊媒師、騎士、パン屋、猫又、共有者
- 人狼陣営: 人狼、黒狼、狂人、狂信者
- 第三陣営: 妖狐、てるてる坊主、疫病神、生存者、復讐者
- 追加状態: 恋人

詳しくは `docs/RULES.md`。

## PCを閉じても動かす場合

このプロジェクトは `Dockerfile`、`PORT`、`HOST=0.0.0.0`、`/health` を用意してあり、Node.jsまたはDockerを動かせるクラウド/VPSへそのまま載せられる構成です。詳しくは `CLOUD-DEPLOY.md` を参照してください。

重要: 現在の部屋データはサーバーのメモリに保存されます。**複数レプリカにはせず1インスタンスで動かしてください。** サーバー再起動時は進行中の部屋が消えます。

## 常時公開について

サーバーは `PORT` と `HOST` 環境変数に対応し、Dockerfileも同梱しています。そのため、Node.jsまたはコンテナを常時起動できるクラウドへ移せます。

ただし現在、部屋・試合状態はメモリ保存です。サーバープロセスを再起動すると進行中の部屋は消えます。長期公開で「再起動しても試合を復元する」段階ではデータベース保存を追加するのが次の課題です。

## PCを閉じても公開する

Render向け設定 `render.yaml` を同梱しています。詳しくは `DEPLOY-RENDER.md` を参照してください。
公開後はngrokもPowerShellも不要です。
